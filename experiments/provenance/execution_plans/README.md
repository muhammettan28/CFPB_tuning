# Execution-time protocol records

These files preserve the exact bytes and hashes of the execution plans recorded
with the experiments. Statements of planned or ongoing work describe the state
at recording time. They are retained for source-identity checks.

The method descriptions are in `protocols/` at the repository root. Completed
results and verification commands are documented in the root README and
`docs/REPRODUCIBILITY.md`. `analysis/repository_layout/FROZEN_ARTIFACTS.json`
records the location and SHA-256 of each preserved plan.
